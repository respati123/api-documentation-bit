# Desktop and cloud workspace redesign

Mode: Operate. Scope: the desktop request workspace and the browser cloud portal, including authentication, workspace navigation, endpoint documentation, activity, and team screens.

Audience and job: developers compose and inspect requests; teammates read contracts and coordinate through cloud workspaces. Both jobs have equal priority. Existing workflows, terminology, behavior, and data remain intact.

## Direction contract

**THESIS:** One graphite workspace connects authoring with reading. Avoid the generic blue on white dashboard arrangement while retaining familiar navigation and controls.

**OWN-WORLD:** Deep graphite ground, panels separated by fine seams, cool text, and one clear blue action/selection accent. Green, amber, and red speak only for meaningful state. Compact sans for controls and monospace for API material. Request and response panels form the signature paired working field.

**STORY:** The user locates a workspace and endpoint, composes or reads the contract, sees response and sync state in place, then takes the next action without searching for it.

**FIRST VIEWPORT:** Desktop keeps the collection rail, a prominent request editor, and a simultaneous response panel. Cloud keeps its workspace rail and page header; documentation uses a clear endpoint index beside the reading pane. The current location and relevant status remain visible.

**FORM:** Compact developer workspace; code-led from the chosen graphite sketch. Selected challenger: digital-design-canon-dark-first-developer-console. seed:ee2591798ee9215b.
